# timeweb-rs

Асинхронный Rust SDK для [Timeweb Cloud](https://timeweb.cloud).

Клиент генерируется из собственной OpenAPI-спецификации вендора, поэтому
покрывает всю публичную поверхность API — **514 операций в 31 области**:
облачные серверы, управляемые базы данных, Kubernetes, проекты, домены, S3,
балансировщики, фаерволы, почта, AI-агенты, AI Gateway, базы знаний, плавающие
IP, VPC, SSH-ключи, образы, выделенные серверы, реестр контейнеров, сетевые
диски и многое другое.

Три причины, по которым это не просто сгенерированный клиент:

- **Он всегда в курсе изменений API.** Еженедельный workflow сравнивает
  вендорённую спецификацию с апстримом и, если API изменился, перегенерирует
  клиент и открывает pull request с диффом API. SDK не расходится с API, который
  он оборачивает.
- **Он разбирает то, что API действительно присылает.** Спецификация и живой
  API расходятся в нескольких местах: nullable-поля, которые API не присылает,
  временные метки без смещения UTC, объединения, которые генератор превращает в
  пустые структуры. Пайплайн генерации чинит эти случаи, так что
  задокументированные ответы десериализуются, а не падают.
- **Он остаётся небольшим.** За каждую область API отвечает своя Cargo-фича,
  поэтому потребителю одной области не нужно компилировать остальные тысячи
  моделей.

```rust
use timeweb_rs::apis::servers_api;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = timeweb_rs::authenticated("your-jwt-token");
    let servers = servers_api::get_servers(&config, None, None).await?;
    println!("{servers:#?}");
    Ok(())
}
```
