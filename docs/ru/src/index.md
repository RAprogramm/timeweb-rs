# timeweb-rs

Асинхронный Rust SDK для [Timeweb Cloud](https://timeweb.cloud).

Клиент генерируется из OpenAPI-спецификации вендора, поэтому покрывает всю
публичную поверхность API — **514 операций в 31 области**: облачные серверы,
управляемые базы данных, Kubernetes, проекты, домены, S3, балансировщики,
фаерволы, почта, AI-агенты, AI Gateway, базы знаний, плавающие IP, VPC,
SSH-ключи, образы, выделенные серверы, реестр контейнеров, сетевые диски и
многое другое.

Почему это не просто сгенерированный клиент:

- **Он всегда в курсе изменений API.** Раз в неделю сценарий сверяет
  вендорённую спецификацию с апстримом и, если API изменился, перегенерирует
  клиент и открывает pull request с диффом. SDK не расходится с API, который
  он оборачивает.
- **Он разбирает то, что API присылает на самом деле.** Спецификация и живой
  API местами расходятся: nullable-поля, которых API не присылает, временные
  метки без смещения UTC, объединения, которые генератор превращает в пустые
  структуры. Пайплайн генерации чинит эти расхождения, так что
  задокументированные ответы десериализуются, а не падают с ошибкой.
- **Он остаётся лёгким.** Каждая область API включается своим флагом Cargo,
  поэтому потребителю одной области не нужно компилировать остальные тысячи
  моделей.

```rust
use timeweb_rs::apis::servers_api;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = timeweb_rs::authenticated("your-jwt-token");
    let servers = servers_api::get_servers(&config, None, None).await?;
    println!("{servers:#?}");
    Ok(())
}
```
