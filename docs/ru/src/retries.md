# Повторы и таймауты

## Таймаут

Каждая конфигурация, построенная через `authenticated`, использует HTTP-клиент
с таймаутом в 30 секунд, поэтому «зависшее» соединение не может заблокировать
задачу навсегда. Таймаут — константа:

```rust
use std::time::Duration;
use timeweb_rs::DEFAULT_TIMEOUT;

assert_eq!(DEFAULT_TIMEOUT, Duration::from_secs(30));
}

Запрос, который упёрся в таймаут, падает с `Error::Reqwest`.

Принесите свой клиент, если дефолтный не подходит — прокси, пул соединений
или другой таймаут:

```rust
let client = reqwest::Client::builder()
    .timeout(std::time::Duration::from_secs(5))
    .build()?;
let config = timeweb_rs::authenticated_with_client("your-jwt-token", client);
```

## Политика повторов

`TimewebClient` повторяет операцию, когда сбой стоит повтора:

- транспортный сбой — запрос не дошёл до API;
- `429 Too Many Requests`;
- любой ответ `5xx`.

Любая другая ошибка возвращается сразу. Задержка растёт экспоненциально от
базовой, удваивается на каждой попытке и ограничена максимальной задержкой;
половина её случайна, чтобы клиенты фермы не повторяли запросы синхронно.

```rust
use std::time::Duration;
use timeweb_rs::RetryPolicy;

let policy = RetryPolicy {
    max_retries: 5,
    base_delay:  Duration::from_millis(200),
    max_delay:   Duration::from_secs(10),
};

let client = TimewebClient::new("your-jwt-token").with_policy(policy);
```

Политика по умолчанию повторяет три раза, начиная с 500 миллисекунд и
ограничивая задержку восемью секундами.

## Retry-After

Ответ `429` может нести заголовок `Retry-After` — числом секунд или HTTP-датой.
Клиент его учитывает: задержка становится ровно такой, какой попросил API, но
не больше максимальной задержки политики.

## Идемпотентность

**Повторяйте только идемпотентные операции.** `POST`, создающий ресурс, может
дойти до API даже тогда, когда ответ не пришёл, — повтор такого запроса может
создать ресурс дважды.

`execute` повторяет всё, что ему дают: политика — свойство клиента, а не
операции. Для неидемпотентной операции используйте `execute_once`:

```rust
let server = client
    .execute_once(|| servers_api::create_server(client.config(), &request))
    .await?;
```

## Политика публична

`RetryPolicy::delay_for` возвращает номинальную задержку повтора — до того,
как к ней применится джиттер. Она детерминирована, поэтому её удобно
проверять в тестах.
