# Поддержка

`timeweb-rs` бесплатен и открыт. Если SDK сэкономил вам время — деплой, который
прошёл гладко, интеграция, которая не дралась, вечер, потраченный не на
отладку десериализатора, — можно сказать спасибо.

> Донат — это спасибо, а не покупка. Он не даёт ни услуг, ни приоритета: задачи
> и pull request и так обрабатываются по мере сил.

## Что дают деньги проекту

- Еженедельная перегенерация клиента вслед за изменениями API вендора.
- Разбор живых расхождений между спецификацией и API: клиент перестаёт
  «отваливаться» на ответах, которые вендор уже отдаёт.
- Время на ответы в задачах и на ревью pull request.
